## 合并规则

1. 图先进本目录，按上表文件名放。
2. 在 960×600 实机里各摆一次，检查锚点、遮挡、白边。
3. 通过后整目录改名为 `art/10_v3_实装/`，六个子目录名原样保留；代码把 `preload` 路径写成 `res://art/10_v3_实装/00_UI界面/...`，文件名不动。
4. 未实装的件继续留在 `10_v3_待出图`，两个目录可并存；每次实装后在 `art/README.md` 末尾追加一行日期与张数，和现有 2026-11-25 的记法一致。
