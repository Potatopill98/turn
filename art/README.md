## 使用约定
- 道具、角色、光效件均为透明底 PNG（RGBA），可直接拖进 Godot 当 Sprite2D/Texture2D。
- 场景底盘（`00_场景/01_镇口定标图.png`、`05_旧宅原型底图_960x600.png`）为整图不透明，作为关卡底图使用。
- 旧宅坐标系基准为 960×600：可走地板 x104–856 / y282–477；旅人 (482,436)、陈守业 (285,338)、陈小满 (705,360)、琴箱近沿 (497,272)。
- 步行循环为四帧横条（3072×768 原图），Godot 中用 AtlasTexture 或 AnimatedSprite2D 按 4 等分切帧。
- 三类头像（平常 / 冲突或停顿 / 转变之后）同名成组，替换时整组替换。
