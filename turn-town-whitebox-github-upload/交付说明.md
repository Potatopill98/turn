# turn-town-whitebox —— 《Turn（转变）》45° 等距小镇白盒底图

## 一句话结论

已生成一张 **96×96 格、64×32 菱形瓦片（45° 俯视／高 32px）** 的等距小镇**白盒（graybox）底图**——
纯灰阶体块占位、不含正式美术，换正式美术只替换同名 PNG。依 GDD 叙事蓝图 v2 落了 5 个故事单元的锚点，
Tiled 源文件与各层 CSV 齐全，结构校验 **0 错误**；Godot 4 侧带等距 TileSet、装饰、POI 接口与**全览相机**，
F6 运行即一屏看全、无需移动。产物可复制进 `D:\godot\新建游戏项目\turn-town-whitebox\` 直接用。

## 白盒（graybox）是什么

用纯几何体块 + 灰阶配色占位，**刻意不含正式美术**。目的是在换美术前就能验证：尺寸够不够、动线顺不顺、
碰撞对不对、叙事锚点落位合不合理。配色三档一眼可辨：

| 元素       | 明度       | 读作                                       |
| -------- | -------- | ---------------------------------------- |
| 地面 floor | 中浅灰      | 可走区域                                     |
| 墙体 wall  | 白顶 + 深灰侧 | 建筑体块（立体）                                 |
| 空白 empty | 深色画布底    | 图外／建筑内部                                  |
| 水面 water | 灰阶波纹     | 椭圆池塘 + 石桥（地图右下）                          |
| 绿地 grass | 浅灰绿      | 游乐场草坪（右上）                                |
| 装饰 prop  | 中深灰      | 现代小镇物件：路灯/电线杆/树/汽车/电动车/长椅/秋千/滑梯/旋转木马/花坛等 |

## 规格与假设

| 项    | 值                                  | 依据                      |
| ---- | ---------------------------------- | ----------------------- |
| 视角   | 45° 等距（isometric），2:1 菱形           | GDD「2D 45度俯视」；H1        |
| 瓦片   | 64×32 px（高 32px）                   | 用户「32px 瓦片」按等距菱形高度理解；H2 |
| 尺寸   | **96×96 格**（较大的小镇）                 | 用户「较大的小镇」；较上一版 64×64 放大 |
| 引擎   | Godot 4.x（本机项目 4.7）                | GDD 试玩基线 Godot 4.7.2    |
| 生成器  | dungeon，32 个街区房间、2 格宽街道、2 格厚建筑墙    | 房间=院落、走廊=街道、墙=建筑体块      |
| 图集   | A 占位图集 + **白盒灰阶**（16 掩码 Wang 自动瓦片） | 用户要求「白盒」                |
| seed | 261124                             | 同 seed 逐字节可复现           |

**H1**：「45° 2D」按等距 2:1 菱形处理，而非正交 45° 旋转贴图。
**H2**：「32px 瓦片」指菱形瓦片高度 32px，宽度按 2:1 取 64px；若你要 32×32 方形瓦片斜视图，结论需下调重做。
**H3**：「较大的小镇」取 96×96 格；要更大改 spec 的 width/height 重生成。

## 校验与证据

- `validate_map.py`：错误 **0**、提示 **1**（等距对象像素坐标提示，已用 `tileX/tileY` 规避，非缺陷）。
- 自动瓦片：wang16，8 个地形角色；现代装饰 289 个（detail 瓦片层，含 80 盏路灯）；池塘水域 151 格、游乐场绿地 192 格；POI 15 个（14 类，按剧情地标重排）。
- 预览已目视验收：全图灰阶无残留彩色、菱形无遮挡、地/墙/空三档分明、街区连贯。
- sha256 全量清单见 `turn-town-whitebox.report.json`。

## 复现

```bash
python whitebox_mapgen.py --spec turn-town-whitebox.source.json \
  --out <输出目录> --engines tiled,godot --scale 2
python modernize_whitebox.py    # 叠加现代小镇内容（幂等，可重复运行）
```

`whitebox_mapgen.py` 覆盖工具箱调色板为白盒灰阶、生成后统一去饱和，不修改工具箱源码，同 spec 逐字节可复现。
`modernize_whitebox.py` 再把地牢内容改成现代小镇：重绘 16 个装饰槽位（路灯/树/车/游乐设施等）、
挖椭圆池塘与石桥、铺游乐场绿地、沿街布 80 盏路灯、按剧情地标重排 POI，并重建 CSV/TMX/预览/全览图。
原始生成物备份在 `_backup_original/`，需要回退可从那里还原。

注意：重新生成会用工具箱默认 Godot 模板覆盖增强版脚本与 IMPORT.md，
届时把 `godot/` 下这几份文件还原为本目录版本即可。要彩色版：把 `WHITEBOX_HEX` 换回默认 `PALETTE_HEX` 重跑。

## 边界与待确认

| 事项                 | 影响          | 当前状态                            |
| ------------------ | ----------- | ------------------------------- |
| 32px 是菱形高度还是方形边长   | 决定瓦片比例与重做与否 | 按 H2 处理，待你确认                    |
