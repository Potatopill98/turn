### 2.2 这一版为什么只用远景层

已生成的场景图是 `far / mid / ground / near` 四层。实际检查发现 **mid 层里烘进了可交互道具**：例如游乐场的秋千、滑梯、围挡、路灯，老宅门前的信箱和门，镇口的告示牌。如果把 mid 整层直接叠上去，场景里会出现两套秋千、两个信箱、两块告示牌，和 `side_prop.gd` 在游戏坐标上的交互物对不上。

所以本版采用的口径是：

- **只接 P0 的 far 远景层**，人物、门、可交互道具仍按原游戏坐标绘制；
- 白天以外用整体色调近似：傍晚偏暖、入夜偏蓝、临走偏灰；
- 这样天空、远山、屋顶、墙面、地下室墙和副食店墙面都能吃到正式美术，同时不破坏“走到哪儿、按 E 对哪个物件”的玩法。

这不是把 12 个场景全部替换成整张插画；`dream` 还没有远景图，仍用程序化占位。

### 2.3 视觉层的小修正

- HUD 上/下纸带替换为纸面资源，文字改成深色，解决原深色条和纸面 UI 割裂。
- 对话/物证/手记打开时加一层 18% 暗幕，让选项纸片和文字在明亮天空前仍然读得清。
- 标题页文案改为「纸面 UI、角色、场景道具与 11/12 场景底图已接入；梦境仍用程序化占位」。
- 标题页内的大块旧黑色剪影已去掉，改成整屏纸底。
- 第一行选项仍保留金色选中框，方向键/鼠标都能选。

## 3. 这版怎么玩

操作不变：

- `A / D` 或 `← / →`：左右走
- `Shift`：跑
- `E / Enter / 空格`：互动、推进对话、确认选项
- `↑ / ↓`：选项或物证选择
- `数字键 1–9`：直接选
- `I`：手记
- `Esc`：关闭当前面板；结局时退出
- 鼠标可点击标题开始、章节卡继续、对话推进、选项行和物证行

主线仍是严格线性七步：

| 步骤 | 目标 | 完成条件 |
|---|---|---|
| 0 | 第一幕 · 归乡 | 进入客厅（`visited_hall`） |
| 1 | 第一幕 · 两件旧物 | 拿照片 + 琴弦字条（`ev_photo`、`ev_note`） |
| 2 | 第二幕 · 散开的谱子 | 小满对话 → 夹谱 → 递照片（`presented_xiaoman`） |
| 3 | 第三幕 · 秋千与旧鞋 | 周德海对话 → 秋千 → 长椅等到入夜 → 捡鞋 → 递鞋（`presented_zhou`） |
| 4 | 第四幕 · 最后一箱 | 唐棠对话 → 搬箱 → 清单 → 递清单（`presented_tang`） |
| 5 | 第五幕 · 磁带 | 回客厅 → 下地下室 → 琴箱 → 梦境右端 → 梦醒（`dream_seen`） |
| 6 | 终幕 · 镇口灯火 | 走到灯下 x1700，做出最后选择（`ending_seen`） |
| 7 | 结局 | 「灯还亮着」或「表针停在四点十分」 |

未完成当前步时，下一道门/选项不会出现；错误时机交互会给出具体回头提示。

## 4. 自动试玩结果

本轮用 `res://tests/flow_linear.tscn` 跑完整条流程，按真实交互顺序执行：

- 开场 → 进客厅 → 拿照片/字条 → 找小满 → 夹谱 → 递照片
- 去游乐场 → 扶秋千 → 坐长椅到入夜 → 捡鞋 → 递鞋
- 去搬家路口 → 搬箱 → 拿清单 → 递清单
- 回地下室 → 琴箱 → 梦境右端 → 梦醒
- 去镇口灯火 → 终章选择 → 结局

最终输出：

```text
FLOW DONE checks=0
```

`checks=0` 表示每一步的步骤号没有错位；结束时 8 件物证齐全，`ending=true`。

## 6. 已知未完成 / 仍是占位

- `dream` 场景没有远景图，梦境仍是程序化暗色几何。
- 场景的 `mid / near / ground` 层没有整层接入；当前地面、门、部分前景遮挡仍由 `side_ground.gd` / `side_door.gd` / `placeholder_art.gd` 绘制。
- 角色只接了 idle/talk；玩家没有 walk 帧，移动时仍用 idle 帧替代；坐下、扶秋千、搬箱、回头等动作态未接。
- 店主没有 portrait，仍用程序化头像。
- FX 尘埃、灯锥、月晕、纸纹、暗角、秋千残影没有接进场景；只有远景层本身的光影。
- 没有音频、存档/读档、设置菜单。
- 副食店、父母闲聊、吴长庚仍是可选内容，不推进主线。
- 手记地图仍是静态节点，不做传送。
