# turn 序章美术交付规格

项目逻辑画布 960×600。序章上方 960×540 显示场景，下方 60 像素显示目标和操作。以下均为画布坐标，原点在左上；交付尺寸是之后换图建议，已有图可继续用于试玩。

| 素材 | 当前状态 | 建议交付和具体内容 |
| --- | --- | --- |
| 镇口空景 | 已接 02_镇口可玩空景.png | PNG 1920×1080。固定镜头斜俯视，石板路从画面下方通往中央巷口，副食店在左。对应 960×540 显示区域时，脚底出生点 (540,480)，巷口互动点 (548,141)。按现有图保留路沿，活动角色、提示由游戏叠加。 |
| 老宅门前空景 | 已接 08_归乡老宅门前.png | PNG 1920×1080。沿用镇口的时段、光向和视角，石板路从下方通到绿木门；出生点 (515,478)，门口互动点 (568,246)，该点处留可站立的石阶前地面。首版门无需动画。 |
| 旧宅空景 | 已接 05_旧宅原型底图_960x600.png | PNG 960×600 或 1920×1200。保留窗口光、木地板和右上角房门。按逻辑画布保留场景框 (68,106) 至 (892,500)，地板约从 y=236 开始。主角从右边进屋，父亲在左、女儿在右、琴箱在后墙中间，沿三处保持通畅。 |
| 主角地图图 | 已接四方向站立，移动时换朝向 | 最终交透明 PNG，统一每帧 192×256。四方向站立各一张，走路可每方向四帧横排 768×256，统一脚底锚点 (96,232)，身高和服饰位置保持一致。参考现有旅人的浅色外套、灰蓝裤和斜挎包。游戏中人物可见高约 54–85 px。 |
| 父亲与女儿地图图 | 仍为占位 | 优先各一张透明 PNG 192×256，脚底锚点 (96,232)。固定斜俯视，父亲微朝右，灰蓝夹克、方下巴和灰鬓；女儿微朝左，暗砖红外套和低马尾。缩到 60–65 px 高时用外轮廓和衣服颜色辨认。以《试弦》定角色比例和配色，站稳，双手可先做简单放松姿势。 |
| 独立合盖琴箱 | 已接 上锁的旧吉他箱.png | 透明 PNG 512×256，旧皮革硬箱斜俯视横放，把手朝画面下方，完整剪影；箱体尺寸约占画布九成宽。实机显示约 102×42 px，互动点位于 (497,272)。 |
| 纸条近景 | 当前用文字按钮 | 可后补透明 PNG 768×512。泛白旧便签，保留干净的文字区域；若做三片，三张图用同一画布和定位，原位合起来刚好填满一张便签。中文由 Godot 排版。 |

风格参考《试弦》的清楚轮廓、暗砖红、灰蓝和木色。换底图时先在 960×600 实机里走一次，核对脚底、墙、路线和 E 提示是否对齐。人物站姿先交一张验证，确认后再成批做动画。
